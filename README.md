# plant-disease-detection-MLSN
A computer vision project developed through the Machine Learning Student Network (MLSN) at UC Davis during Spring 2026.

## Overview

This project uses transfer learning and the ResNet34 neural network architecture to classify plant leaf images into three categories:

* Healthy
* Rust
* Powdery mildew

The project used a balanced dataset of 1,530 plant leaf images from Kaggle.

## My Contributions

* Developed a Python-based interactive frontend hosted on Hugging Face Spaces.
* Analyzed and augmented the plant leaf image dataset as part of the team project.
* Participated in model evaluation, including confusion matrix analysis, prediction confidence analysis, and review of misclassified images.
